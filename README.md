# GiveBack

Give what you don't need. Find what you do.

GiveBack is a community-first web experience for giving useful items a second home. The first release is a safe, privacy-conscious product prototype focused on discovery, reuse, and responsible handoffs.

## Product principles

- Keep useful things in circulation.
- Never require public personal contact details.
- Make listings easy to understand.
- Put safety before speed.
- Build a calm, welcoming community experience.

## Stack

Next.js 16, React, TypeScript, Tailwind CSS, and Vercel.

## Development

```bash
npm install
npm run dev
```

Verification:

```bash
npm run verify
```

## Status

GiveBack is an early production-quality prototype. Real account, moderation, messaging, and database services should be added before accepting unrestricted public listings.
